# Complete recorded evidence

[Recorded notebook](recorded_notebook.ipynb) retains the original execution cells and saved outputs, including failures, with publication path/credential redactions where necessary. It is an archive, not the offline viewing notebook or a portable execution entry point. Its historical annotations and source-location strings can refer to the original workspace; use [the public demo](../demo.ipynb) and [case README](../README.md) for current navigation.

Setup snapshots document the code and instructions associated with this run. They are not substitutes for the root package and are not installed automatically. Scientific tool snapshots under `search/setup/` record the method and database fingerprint; licensed Thermo-Calc software/databases are not distributed here.
