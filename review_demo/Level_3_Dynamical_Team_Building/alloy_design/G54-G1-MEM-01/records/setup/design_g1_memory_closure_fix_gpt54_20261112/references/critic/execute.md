# Critic guidance: execute

Check determining quantities, signs, units, source IDs and meaningful ties for the assigned calculation. Accept correct calculations even if an alloy fails a constraint; return necessary design work separately to the manager. A hard violation cannot be compensated by low J. Report passing high-temperature L12 values as feasible, not favorable/unfavorable design trends. Missing values stay unknown. A narrow execution review needs a concise evidence check and handoff; the full R1–R6 audit belongs to final design review.

Interpret CSC, FR and HCS jointly; an interval ratio is not an absolute interval. Liquid at an upper disappearance boundary excludes calling it a solid-state treatment solvus, but does not rule out all treatment below melting. Equilibrium and terminal Scheil phase amounts are distinct.
